Medlab

### ECG Waveform Generation
- Realistic ECG waveform generation using mathematical models
- Support for multiple rhythms (Normal Sinus, Atrial Fibrillation, Bradycardia, Tachycardia)
- Abnormalities: ST elevation/depression, Q waves, T wave inversion, axis deviations
- Standard ECG grid overlay (1mm and 5mm squares)

### Answer Validation
- Keyword-based answer validation with natural language understanding
- Context-aware feedback based on ECG parameters
- Progressive hint system for incorrect answers

### Authentication
- Simple client-side authentication (free access)
- User session management with localStorage
- Protected routes for dashboard access
